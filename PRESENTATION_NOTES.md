# How to explain this portfolio

## Short introduction

"This is my responsive portfolio website. It introduces me, shows my current skills and education, describes my NPTEL certificate and the ShopEase project I am still developing, and gives visitors a way to contact me. I built the page with HTML, CSS, and JavaScript."

## What each file does

- `index.html` contains the page content and section structure: introduction, about, skills, projects, education, learning experience, certification, contact, and footer.
- `styles.css` controls colors, spacing, typography, cards, responsive layouts, mobile navigation appearance, and animations.
- `script.js` opens and closes the mobile menu, updates the footer year, reveals content as it scrolls into view, and prepares a message in the visitor's email app.
- `assets/` contains the profile placeholder and project illustrations. Replace the profile placeholder with your own photo.

## How to run in VS Code

1. Extract `portfolio-site.zip` to a folder.
2. In VS Code, choose **File → Open Folder** and select the extracted `portfolio-site` folder.
3. Open `index.html`. Use the Live Server extension if installed, or open the file in a browser.
4. To present the code, show `index.html` first, then `styles.css`, then `script.js`.

## Honest project description

ShopEase is currently a frontend prototype for an online electronics store. It has product browsing, search and category filters, sorting, product details, cart and wishlist behavior, and a demo checkout. It does not yet have a backend, saved server-side orders, or real payment processing. Present it as work in progress.
